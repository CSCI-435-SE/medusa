What is one thing you learned about the codebase or about software engineering practice?  
One thing I learned about the codebase is how the routing layer works. Medusa's routing layer is where an HTTP request turns into business logic, similar to that of a service layer, though it manages the HTTP routes similar to a controller layer. Medusa doesn't keep a central route table, instead, at startup, the framework's routes loader (routes-loader.ts) walks packages/medusa/src/api/ and turns each folder path into a URL. The route to the product id story (\#66) relies on three pieces of middleware: authentication, global middleware, and route specific middleware. A request handler would then be used for a request to read parameters, enforce a guard, mutate data, then respond. Architecture like this is efficient because it allows for any errors that are found or that occur to be handled in one place by error-handler.ts, which is the framework’s error handler.
